- AI-powered technical documentation assistant for PDF manuals.
- Semantic search using Sentence Transformers and FAISS.
- Context-grounded answers using Groq with document and page citations.
- **Tech:** Python, RAG, FAISS, Streamlit, PyMuPDF.

**2. Ground-Level Ozone Prediction**

- Time-series simulation exploring machine learning approaches to ground-level ozone prediction.
- Developed during my research internship at ISRO SAC.
- **Tech:** Python, XGBoost, Machine Learning.

- Machine learning project exploring student performance prediction.
- **Tech:** Python, Pandas, Scikit-learn.
